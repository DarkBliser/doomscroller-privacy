# Doomscroller – Privacy / Datenschutz

Privacy policy pages for the game **Doomscroller** (Android package `com.darkbliser.doomscroller`), published with GitHub Pages.

- Start page: https://darkbliser.github.io/doomscroller-privacy/
- English: https://darkbliser.github.io/doomscroller-privacy/privacy-en.html
- Deutsch: https://darkbliser.github.io/doomscroller-privacy/privacy-de.html

Use the **English** link as the privacy policy URL in the Google Play Console.

`DATA-SAFETY.md` lists the answers for the Play Console "Data safety" form (English + German).
